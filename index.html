📊 Ozon Profit Report (Локальный расчет)

Этот инструмент НЕ требует API ключей. Он рассчитывает прибыль на основе файла выгрузки из ЛК Ozon.

📥 Загрузка данных из Ozon

Скачайте отчет "Заказы" или "Реализация товаров" из ЛК Ozon (CSV/Excel) и загрузите его ниже.

📁 Нажмите сюда, чтобы выбрать файл выгрузки Ozon (CSV/XLSX)

Поддерживаются: .csv, .xlsx, .xls

⚙️ Себестоимость и Налоги

Способ расчета себестоимости

Пример: если товар стоит 1000₽, а процент 70, то себестоимость считается как 700₽.

📁 Загрузить файл с закупочными ценами (CSV/JSON)

Формат: sku,cost или JSON массив

💡 Почему нет API?

Браузеры блокируют прямые запросы к Ozon API (CORS). Этот метод надежнее: вы контролируете данные, и отчет работает мгновенно без лимитов запросов.
